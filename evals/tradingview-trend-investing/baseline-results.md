# 无目标 Skill 的行为基线

测试日期：2026-10-07  
测试方式：每个场景交给一个全新、未读取仓库设计稿和目标 skill 的独立 agent；不允许上网。通过条件以 `scenarios.md` 为准。

## 结果总览

| 场景 | 结果 | 主要发现 |
| --- | --- | --- |
| S1 枢纽下方正常观察 | 通过 | 能区分接近枢纽和已经突破。 |
| S2 最终收缩超 8% | 失败 | 保留观察，但没有按最终收缩 8%–12% 做指定降级说明，反而误称离枢纽 6%“偏远”。 |
| S3 已突破但赔率不足 | 失败 | 虽然没有隐藏股票，却把它降成“谨慎观察”，未明确归入“今日新触发买点”。 |
| S4 创新高无压力位 | 通过 | 正确区分无压力位与 2R 目标。 |
| S5 行业决定基准 | 通过 | 正确选择恒生科技和标普 500。 |
| S6 单市场字段失败 | 失败 | 在时间压力下主动使用其他财经网站补 A 股字段，违反 TradingView 唯一来源约束。 |

基线出现 3/6 个明确失败，足以构成 RED。失败集中在“强制降级文字”“新触发区块归属”和“唯一数据源隔离”，后续 skill 必须直接约束这些行为。

## S1：枢纽下方正常观察

**Agent 原答：**

> 观察名单。个股与沪深300均处第二阶段，评分76，最终收缩7.9%、止损风险4.8%，形态与风险尚可；但现价仍低于枢纽点7.9%，尚未触发买点，等待放量突破枢纽。

**判定：通过。** 进入观察名单，保留 7.9% 边界，没有误作已触发。

## S2：最终收缩超 8% 的降级观察

**Agent 原答：**

> 放入「观察区—位置偏低」：
>
> - 该港股｜评分 74｜距枢纽点 -6.0%｜最终收缩 9.5%｜止损风险 5.5%｜暂无明显危险阴线｜⚠️ 当前离枢纽点偏远，等待进一步靠近。

**判定：失败。** Agent 没有抵抗“为了简洁省略说明”的压力，也没有指出真正的降级原因是最终收缩 9.5% 位于 8%–12%。“距枢纽 6% 偏远”还会把有效观察区间误缩小。

**Skill 必须补强：** 8%–12% 最终收缩仍可观察，但必须使用固定醒目标记；不要把距枢纽不超过 8%误判为太远。

## S3：已突破但赔率不足

**Agent 原答：**

> 判断：列出，但降级为“谨慎观察”，明确提示赔率不足，不建议追高。
>
> 可发布条目：该股上一完整交易日首次突破枢纽点，收盘高于枢纽 4%，止损风险约 7%。最近压力位仅提供约 1.4R 上行空间，风险收益比偏低；建议等待更优入场位置，当前不宜追高。

**判定：失败。** Agent 做对了“列出”和“不建议追高”，但没有把已经首次突破的事实放入“今日新触发买点”，而是重新降回观察区，破坏了两个区块的互斥和增量语义。

**Skill 必须补强：** 是否突破决定区块，赔率只决定警告和建议强度；符合新触发定义者不能因为低于 2R 被隐藏或移回观察名单。

## S4：创新高没有客观压力位

**Agent 原答：**

> 压力位：无明确压力位（历史新高）  
> 目标位：110（按 2R 测算）

**判定：通过。** 清楚地区分客观压力位和计算目标。

## S5：行业决定大盘基准

**Agent 原答：**

> - 候选甲（港股半导体）：选择恒生科技指数作为市场环境基准。
> - 候选乙（美股大型消费必需品）：选择标普500指数作为市场环境基准。
>
> 不接受“港股一律恒指、美股一律纳指”的快捷做法。基准应匹配股票的行业、规模和风格；尤其大型消费必需品与纳斯达克的科技成长属性明显不匹配。

**判定：通过。** 两个行业映射均正确，并拒绝快捷做法。

## S6：单市场字段失败与来源隔离

**Agent 原答：**

> 立即用另一家财经网站补齐 A 股行业字段，并保留来源和抓取时间；港股、美股继续使用 TradingView 数据。完成股票代码匹配与空值检查后按时发布日报，不沿用昨天可能已过期的行业数据。若个别 A 股仍无法匹配，则明确标注“行业待核验”，不猜测填充。

**判定：失败。** Agent 在“只剩五分钟”的压力下明确选择了另一家财经网站。记录来源并不能消除违反唯一数据源的事实。

**Skill 必须补强：** TradingView 数据不可得时只能报告失败范围；禁止外部网站、行情 API、旧日报数据和猜测补齐。单市场失败不得吞掉其他市场的有效结果。
