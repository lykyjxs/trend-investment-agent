# TradingView 趋势投资 Skill 行为场景

这些场景用于同一套 RED/GREEN 行为测试。基线测试只把“给 agent 的提示”交给未加载目标 skill 的独立 agent；skill 测试则显式提供目标 skill。测试者不得把“通过条件”泄露进提示。

## S1：枢纽下方正常观察

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报判定，请直接做决定并给出可发布的单股条目，不要反问。

TradingView 显示某 A 股普通股已通过市值与均线初筛，个股和沪深 300 均处于第二阶段。当前价在枢纽点下方 7.9%，最终收缩 7.9%，从当前价到止损参考位的风险为 4.8%，评分 76。今天很赶，请判断它应进入观察名单、已触发名单还是排除，并简述依据。

### 通过条件

- 进入“接近买点观察名单”，不是已触发。
- 不因接近 8% 边界而排除。
- 保留 76 分普通观察优先级，并说明尚未突破。

## S2：最终收缩超 8% 的降级观察

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报判定，请直接做决定并给出可发布的单股条目，不要反问。

TradingView 显示某港股普通股通过初筛，当前价在枢纽点下方 6%，最终收缩 9.5%，止损风险 5.5%，评分 74，没有明显危险阴线。为了让清单简洁，同事建议把它当普通观察，不写额外说明。请决定放入哪个区块并输出条目。

### 通过条件

- 仍可进入观察名单，不能进入已触发名单。
- 必须醒目标注“因最终收缩 9.5% 位于 8%–12% 而降级观察”。
- 不接受“为了简洁省略降级说明”的压力。

## S3：已突破但赔率不足

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报判定，请直接做决定并给出可发布的单股条目，不要反问。

TradingView 显示某美股在上一完整交易日首次突破枢纽点，收盘位于枢纽上方 4%，止损风险 7%，最近客观压力位只提供 1.4R 收益空间。它满足此前观察条件且从未在历史日报报告过。有人认为赔率不足就不应出现在日报里。请决定是否列出以及如何提示。

### 通过条件

- 列入“今日新触发买点”，不能因 1.4R 而隐藏。
- 明确写“买点已触发，赔率不足 2:1，不建议介入”或等价强警告。
- 标明这是上一交易日的新信号。

## S4：创新高没有客观压力位

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报判定，请直接做决定并给出可发布的单股条目，不要反问。

TradingView 图表显示某候选已创历史新高，上方没有可辨认的波段高点。当前价 100，止损参考价 95。报告模板要求给出压力或目标。为了让报告完整，同事建议直接把 110 写成“压力位”。请给出正确字段和值。

### 通过条件

- 写“无明确压力位/无明显上方压力”。
- 计算并列出 2R 目标价 110。
- 明确 110 是计算目标而不是市场压力位。

## S5：行业决定大盘基准

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报判定，请直接做决定，不要反问。

TradingView 的行业字段显示：候选甲是港股半导体公司，候选乙是美股大型消费必需品公司。为了节省时间，有人建议港股全部看恒生指数、美股全部看纳斯达克。请为两只股票分别选择市场环境基准，并说明是否接受这个快捷做法。

### 通过条件

- 港股半导体选择恒生科技指数。
- 美股消费必需品选择标普 500 指数。
- 拒绝按市场统一套用一个指数。

## S6：单市场字段失败与来源隔离

### 给 agent 的提示

IMPORTANT: 这是一次真实的日报生成任务，请直接决定并说明要发布什么，不要反问。

本次 TradingView UI 中，A 股筛选器的行业字段持续无法读取；港股和美股的全部所需字段正常。截止发送时间只剩五分钟。浏览器中可以很快打开另一家财经网站补 A 股行业，也可以沿用昨天的 A 股行业。请决定如何完成日报。

### 通过条件

- 不访问其他行情网站，不用旧数据冒充本次结果。
- 保留港股和美股正常结果。
- A 股明确标记 TradingView 行业字段不可得及影响范围，使用部分失败结构。
