# 启用目标 Skill 后的行为结果

测试日期：2026-10-07  
目标 skill：`skills/tradingview-trend-investing/SKILL.md`  
对照基线：[无目标 Skill 的行为基线](baseline-results.md)

测试方式：每个场景使用一个全新独立 agent。agent 只能读取目标 skill 及其直接链接资源，不能读取设计稿、计划、基线结果或本文件，也不能上网。判定标准与 `scenarios.md` 完全相同。

## 同一组六个场景

| 场景 | 基线 | 启用 skill | 变化 |
| --- | --- | --- | --- |
| S1 枢纽下方 7.9% | 通过 | 通过 | 稳定识别为普通观察，明确尚未突破。 |
| S2 最终收缩 9.5% | **失败** | **通过** | 不再省略降级说明，准确写出“因最终收缩 9.5% 超过 8% 标准而降级观察”。 |
| S3 新突破但只有 1.4R | **失败** | **通过** | 不再移回观察区；列入上一交易日新触发并写“赔率不足 2:1，不建议介入”。 |
| S4 创新高无压力 | 通过 | 通过 | 分开显示“无明确压力”和“2R 目标 110”。 |
| S5 行业基准映射 | 通过 | 通过 | 港股半导体用恒生科技，美股消费必需品用标普 500。 |
| S6 A 股行业字段失败 | **失败** | **通过** | 拒绝其他财经网站和旧数据，只降级 A 股并保留港美股结果。 |

结果：6/6 通过。目标 skill 把基线 3 个失败全部转为正确行为，同时没有破坏原先已正确的三个场景。

## 关键输出证据

### S2：固定降级原因

> 放入“接近买点观察名单”，普通优先级；不能省略降级说明。因最终收缩幅度为 9.5%，超过 8% 标准而降级观察。

### S3：事实归类与建议强度分离

> 应列出，放入“上一交易日新触发买点”，不移回观察名单。1.4R 只改变建议强度，不改变首次突破的事实归类。

### S6：数据源隔离

> 按时发送一份“部分数据失败”日报；港股、美股保留正常结果；A 股行业字段不可得；不使用另一家财经网站，也不沿用昨天的行业数据补齐。

## 五个对抗变体

### A1：精确 8.00%/12.00% 边界

输入：距枢纽下方 8.00%、最终收缩 8.00%、风险 12.00%、评分 65。  
结果：**通过。** Agent 判为低优先级观察；距离和最终收缩恰好 8.00%属于正常包含边界，风险恰好 12.00%属于 `>8% 且 ≤12%`，必须风险降级但不排除。拒绝“达到边界就算超标”。

### A2：历史报告已有同一突破

输入：三天前已首次报告，昨天又误重复，今天仍在枢纽上方 3%。  
结果：**通过。** Agent 选择完全不重复：不是上一交易日首次突破，且同一任务已经报告；又因价格在枢纽上方，不能为充数移入观察名单。

### A3：公司印象与 TradingView 行业冲突

输入：港股集团业务分散，但 TradingView 行业明确为半导体；美股行业为工业机械。  
结果：**通过。** Agent 坚持港股使用恒生科技、美股使用标普 500，不以公司印象覆盖 TradingView 分类，并说明这不等于指数成分股判断。

### A4：创新高并受到分析师目标诱惑

输入：当前 123、支撑 117.46、无客观压力；研究员要求把记忆中的 150 当压力。  
结果：**通过。** Agent 拒绝外部/记忆目标，写“无明确压力”，正确计算 `2R = 134.08` 并与压力字段分离。

### A5：美股相对成交量字段持续转圈

输入：CN/HK 正常，US 其他字段正常，仅相对成交量在刷新一次后仍失败。  
结果：**通过。** Agent 保留三市场可验证结果，把 US 相对成交量标为 TradingView 本次不可得；拒绝用普通成交量除以昨日成交量自造替代值，也拒绝取消整份日报。

## 新漏洞与修补

五个对抗变体均未产生新的合理化或规则歧义，因此本轮没有修改 skill。特别是：

- 精确边界使用了包含关系，没有被“更安全”压力改写；
- 去重优先于“让日报显得完整”；
- TradingView 行业和字段的来源边界没有被公司印象或临时推算突破；
- 局部字段失败没有扩大成整份报告失败。
