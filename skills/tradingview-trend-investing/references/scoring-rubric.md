# 100 分评分表

评分评价形态质量和风险，不把“是否已经突破”和成交量直接计入分数。先应用硬性排除，再评分；高分不能覆盖硬性排除。

## 硬性排除与降级优先

| 条件 | 处理 |
| --- | --- |
| 最终收缩 > 12% | 排除 |
| 潜在亏损 > 12% | 排除 |
| 明显 Stage 4、放量大跌或跌破长期均线 | 排除当前买点，必要时排除观察 |
| 观察候选位于枢纽下方超过 8% | 不进入接近买点观察名单 |
| 总分 < 60 | 不进入观察名单 |
| 最终收缩 > 8% 且 ≤ 12% | 只观察并写固定降级说明 |
| 潜在亏损 > 8% 且 ≤ 12% | 只观察并写风险降级说明 |

## 分数组成

| 项目 | 满分 |
| --- | ---: |
| 大盘环境 | 15 |
| 个股第二阶段趋势模板 | 20 |
| 相对强弱与行业地位 | 10 |
| VCP 整体结构 | 15 |
| 最终收缩 | 20 |
| 止损与风险收益 | 20 |
| **总计** | **100** |

## 1. 大盘环境：15 分

- 15：对应基准明确处于 Stage 2，周线和日线相互确认。
- 7：处于 Stage 1 向 Stage 2 过渡，或周线尚未完全确认。
- 0：Stage 3/4 或环境无法可靠读取。

只评价对应指数，不把个股均线证据重复放进本项。

## 2. 个股第二阶段趋势模板：20 分

- 价格位于 50/150/200 日均线上方：0–6。
- SMA50 > SMA150 > SMA200：0–4。
- SMA150 和 SMA200 方向向上：0–6。
- 高低点抬高且“大涨小回”：0–4。

20 分表示完整 Stage 2 趋势模板；12–19 表示大体处于第二阶段但仍有一项较弱；低于 12 通常不满足接近买点观察要求。

## 3. 相对强弱与行业地位：10 分

- 相对对应大盘保持强势：0–4。
- 接近一年高点，或较一年低点至少上涨约 30%：0–3。
- 行业领头羊或顶级竞争者证据：0–3。

只使用 TradingView 可见行业和对比图；无法确认行业地位时不猜测，相关分数记 0 并列入缺口。

## 4. VCP 整体结构：15 分

- 两到三次以上可辨认收缩/稳固：0–5。
- 波幅总体逐次缩小：0–4。
- 回调量能总体收缩：0–3。
- 形态持续时间足以换手：0–3。

不是看到一个三角形就给满分。宽幅震荡、收缩次序混乱或量价异常时降分。

## 5. 最终收缩：20 分

- 幅度 `≤ 8%`：0–10；越紧且结构自然越高。
- 持续至少三个交易日：0–4。
- 回调成交量收缩、价格动作稳定：0–6。

幅度 `> 8% 且 ≤ 12%` 时，幅度部分为 0，本项最高 10，且只能降级观察。超过 12%直接排除。

## 6. 止损与风险收益：20 分

- 支撑与止损结构清晰：0–4。
- 潜在亏损 `≤ 5%`：8；`> 5% 且 ≤ 8%`：4；`> 8% 且 ≤ 12%`：0 并只观察；`> 12%`：排除。
- 最近客观压力提供 `≥ 2R`：8；`≥ 1.5R 且 < 2R`：4；`< 1.5R`：0。

创新高无明确压力位时，不能凭空给赔率分；使用 2R 目标辅助展示，并根据支撑清晰度和上方供给情况保守给分，在“缺口”中写明无客观压力位。

## 优先级与报告用语

- 80–100：高优先级，形态较完整，等待或复核突破。
- 70–79：普通观察，列出一到两项不足。
- 60–69：低优先级，必须清楚列出缺失条件。
- < 60：排除观察名单。

评分后仍要再次执行硬门槛检查。报告中列出总分、六项分项、优势、缺口和主要风险，不能只给一个没有依据的总分。

## 不计分的状态字段

以下信息必须展示但不计入 100 分：是否突破枢纽、突破日期、枢纽距离、成交量、相对成交量及“充足/一般/不足”标签。用户下单前可据此人工确认。
